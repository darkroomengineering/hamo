# Restructure `hamo` into a `packages/hamo` monorepo

## Context

Today the publishable `hamo` library lives at the **repo root** (`src/`, `test/`, `dist/`,
and the publishable `package.json` are all top-level), and `playground/` is the only
workspace member. Because the root package is not a member of its own `workspaces`, the
playground cannot link the local library — it has to use a `"hamo": "file:.."` hack, and
until recently was silently pulling the **published** `hamo@0.3.2` from npm (typeless),
which broke the playground build. (See the earlier `fix(playground)` commits.)

Moving the library into `packages/hamo/` makes it a real workspace member. The payoff:
the playground links it with idiomatic `workspace:*`, the `file:..` hack disappears, and
the repo gains a conventional monorepo shape that can hold more packages later.

**Directory name:** `packages/hamo` (mirrors the npm package name; chosen over `packages/react`).

## Target structure

```
/                          # private workspace root
  package.json             # NEW: private, workspaces, delegating scripts
  bun.lock                 # single lockfile (regenerated)
  .github/                 # CI (updated)
  .gitignore .tldrignore .tldr/ .vscode/ .claude/ plans/
  packages/
    hamo/                  # the library (moved verbatim, history preserved via git mv)
      package.json  src/  test/  tsconfig.json  tsdown.config.ts
      bunfig.toml  biome.json  .npmrc  README.md  CHANGELOG.md  LICENSE
  playground/              # unchanged location; link + 2 import paths updated
```

`docs/` is **removed** (dead: its `App.jsx` imports `../src/hooks/*`, a path that has
never existed; already excluded from lint + typecheck). Verify no live references first.

## Moves (use `git mv` to preserve history)

Into `packages/hamo/`: `src/`, `test/`, `package.json`, `tsconfig.json`,
`tsdown.config.ts`, `bunfig.toml`, `biome.json`, `.npmrc`, `README.md`, `CHANGELOG.md`,
`LICENSE`. (`dist/` is gitignored — not moved, just rebuilt in its new home.)

Stay at root: `.github/`, `.gitignore`, `.tldrignore`, `.tldr/`, `.vscode/`, `.claude/`,
`plans/`, `bun.lock`. Delete: `docs/`.

## Path / config edits

| File | Change |
|---|---|
| **`package.json` (new root)** | `"private": true`, `"workspaces": ["packages/*", "playground"]`, scripts delegate: `build`/`typecheck`/`lint`/`format`/`test` → `bun --filter hamo <script>`; a `dev` that runs lib watch + playground. No deps. |
| **`packages/hamo/package.json`** | Remove the `"workspaces": ["playground"]` field (root owns workspaces now). Everything else — `name: hamo`, `exports`, `files: ["dist"]`, version, deps, `prepublishOnly`, publish scripts — moves **verbatim**. |
| **`packages/hamo/tsconfig.json`** | Drop now-irrelevant excludes `"playground"`, `"docs"`, `"plans"` (keep `dist`, test excludes). `rootDir`/`outDir` stay (relative to moved file). |
| **`packages/hamo/biome.json`** | Drop `!playground`, `!docs`, `!plans` from `includes` (not under the package). |
| **`playground/package.json`** | `"hamo": "file:.."` → **`"hamo": "workspace:*"`** (the whole point — now resolvable). |
| **`playground/www/pages/index.astro`** & **`react.astro`** | `import pkg from '../../../package.json'` → `'../../../../packages/hamo/package.json'` (one extra `../` + into `packages/hamo`). |
| **`.gitignore`** | **No change** — the unanchored `dist` pattern already matches `packages/hamo/dist` at any depth. |
| **`bun.lock`** | Regenerated by `bun install` (do not hand-edit). |

### CI — `.github/workflows/ci.yml`

- `bun install --frozen-lockfile` — unchanged (root install covers all workspaces).
- `bun run typecheck` / `lint` / `build` — unchanged **iff** the new root scripts delegate via `--filter hamo` (they will).
- `bun test` → **`bun run test`** (so it routes through the delegating script into `packages/hamo`, where `bunfig.toml` provides the `test/setup.ts` preload — otherwise happy-dom never registers and tests fail).
- React-18 matrix pin `bun add -d react@18 …` → **`bun add --cwd packages/hamo -d react@18 …`** (must target the library workspace, not the root).

### CI — `.github/workflows/publish.yml` (highest risk)

- typecheck/lint/build steps via root delegation (OK); `bun test` → `bun run test`.
- `npm publish --provenance --access public` → **`cd packages/hamo && npm publish --provenance --access public`** (today it would publish the private root). `prepublishOnly: tsdown` runs in-package; `.npmrc` (`workspaces-update=false`) resolves from the package dir.

## Verification (run after the move, before commit)

1. `bun install` — lockfile regenerates; confirm `playground` resolves `hamo` to `packages/hamo` via `workspace:*` (not a registry version).
2. `bun run typecheck` → clean; `bun run lint` → clean.
3. `bun run test` → **46 pass** (proves the `bunfig.toml` preload is found in its new home).
4. `bun run build` → dist emitted in `packages/hamo/dist`.
5. `cd packages/hamo && npm pack --dry-run` → tarball contents (`LICENSE`, `README.md`, `dist/**`) **identical** to pre-move; `dependencies` still none.
6. `cd packages/hamo && npm publish --dry-run` → confirms publish runs from the right dir.
7. `cd playground && bun run build` → `astro check` 0 errors (hamo resolves to local), 2 pages built.
8. `git mv` used throughout → `git log --follow packages/hamo/src/...` shows preserved history.

## Execution notes

- Done inline with the verification gates above (not delegated) so breakage is caught step-by-step; the path edits are interdependent.
- Commits: (1) `refactor: restructure library into packages/hamo monorepo` (the move + all wiring), (2) `chore: remove dead docs/ directory`. Then push to `feat/v1`.
- The shipped package must be byte-identical in output — step 5 is the gate that proves consumers are unaffected.
- Optional follow-up (not in scope): clear stale `.tldr/cache` so TLDR stops referencing old paths.
